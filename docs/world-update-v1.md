# SpriteDex WORLD UPDATE v1

## Cadence

Run weekly for each active Region after external biodiversity imports have completed.

Recommended order:

1. import/refresh external observations,
2. resolve external observations to local species/taxa,
3. refresh external observation Region membership,
4. calculate Region Encounter Tiers,
5. refresh user Region game state,
6. compare current metric snapshots with the previous weekly snapshot,
7. publish user-facing Region changes.

## What can change

A weekly WORLD UPDATE may produce:

- a newly documented Regional Catalogue taxon,
- a taxon entering or leaving the Active Dex,
- a stable Encounter Tier change,
- a user's completion denominator changing,
- regional ranking changes,
- seasonal activity changes.

## User-facing language

Prefer:

> **WORLD UPDATE COMPLETE**  
> Ganaraska Forest has changed since last week's survey refresh.  
> 3 taxa entered the seasonal Dex.  
> 1 Encounter Tier changed.  
> Your completion is now 84 / 312.

Avoid claiming that a species became biologically rarer or more abundant unless a separate scientific analysis supports that conclusion.

## Important fairness rule

When the Active Dex denominator changes, preserve historical achievements. If a player had 100% completion at a prior snapshot, that achievement remains part of their history even when seasonal/ecological updates introduce new targets.

## Future snapshot-based leaderboards

Leaderboards should be computed from explicit period snapshots (week, season, year, all-time), not from mutable live counters alone. This makes historical ranking reproducible and allows new players to compete in fresh seasons.
